# CHATTERBOX 




## What is this project about?
->CHATTERBOX is a real-time messaging application built completely from scratch using Java. The goal of this project is not only to build a chat application but also to learn software engineering concepts by implementing them in a real project.






## Features of current version (V0.1) :-
-> Username Input: When the app starts, the user will enter a unique username.

-> Client-Server Architecture: The client connects to a central server, and the server manages all connected clients.

->Real-Time Messaging: Users can send and receive messages instantly in a public chat room.

-> Broadcast: Every message sent by a user is broadcast to all connected users.

-> Join/Leave Notifications: The system announces when a user joins or leaves the chat.

-> Command to Exit: Users can type a specific command (e.g., /exit) to disconnect from the chat safely.

-> Timestamping: Each message displayed will include a timestamp so users can see when messages were sent.

-> Console-Based Interface: The entire app runs in a terminal—no graphical interface yet.

That’s it for Version 0.1!
